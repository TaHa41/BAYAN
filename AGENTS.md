# BAYAN v1 engineering rules

1. Do not silently restore the legacy implementation.
2. Retrieval precedes generation.
3. Never invent evidence or sources.
4. Never weaken manager authentication.
5. Never expose secrets to the client.
6. Provider failure must degrade gracefully.
7. Every database change is versioned.
8. Run typecheck, tests and Wrangler dry-run before declaring a release.
